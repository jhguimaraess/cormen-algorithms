# Cormen Algorithms

Repositório dedicado ao estudo do livro **Algoritmos: Teoria e Prática**, de Thomas H. Cormen e outros autores.

O objetivo é aprofundar o entendimento sobre algoritmos por meio da leitura, análise e implementação prática dos conteúdos apresentados no livro.

As implementações são feitas em Java, seguindo os algoritmos e conceitos estudados ao longo dos capítulos.
